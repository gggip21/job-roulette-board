설정 페이지 __SITE__

한눈에 보기

현황판은 방송 화면 구석에 띄워두는 투표 집계표예요. 시청자가 후원하며 직업을 적으면, 그 직업의 표가 올라가고 순위와 확률(%)이 바로 바뀌어요.

  1. 설정 페이지에서 제목·후원 규칙·투표 불가 직업·테마를 정하고 내 현황판 파일 저장 (한 번만)
  2. OBS에 브라우저 소스로 추가하고 화면에 배치 (한 번만)
  3. 방송 중 후원이 오면 OBS 상호작용 창에서 직업과 표를 입력 (매번)
치지직·SOOP·유튜브 후원은 자동으로 들어오지 않아요. 3번은 직접 입력해야 하며, 입력한 내용은 OBS를 껐다 켜도 남아 있어요.

1. 설정 페이지에서 내 파일 만들기

크롬이나 엣지에서 설정 페이지를 열어요. 왼쪽에서 고치면 오른쪽 미리보기에 바로 반영되고, 설정은 그 브라우저에 자동으로 저장돼요.

항목설명
기본 정보제목, 부제(비우면 숨김), 프로필 이미지 또는 글자(이모지 가능)
테마 색준비된 테마를 고르거나 메인·강조·포인트·배경 색을 직접 지정
후원 규칙후원 단위(원/치즈/별풍선/직접 입력)와 1표 금액. 특정 직업만 1표 금액이 다르면 "1표 금액이 다른 직업"을 켜고 직업과 금액을 고름. 메소 후원도 받으면 "메소 후원도 표로 받기"
투표 불가 직업눌러서 켜고 끄기. 투표 불가 직업은 OBS 편집창 버튼에서 빠지고, 입력도 막혀요
리롤받을 때만 켜기. 횟수 1~3회, 회차별 금액
디데이마감·추첨 날짜. 당일은 D-DAY, 지나면 D+
표시총 후원 금액, 판 아래 투표 불가 목록, 작은 제작 표시, 한 페이지 개수, 넘김 간격

다 고쳤으면 💾 내 현황판 파일 저장을 눌러요. roulette-board.html 파일이 받아져요. 지우지 않을 폴더(예: 문서\방송\)로 옮겨 두세요. 파일을 옮기거나 지우면 OBS에서 현황판이 사라져요.

설정을 따로 하지 않고 바로 쓰고 싶으면 설정 페이지 맨 위의 기본 설정 그대로 받기로 받아도 돼요.

2. OBS에 띄우기

  1. OBS에서 현황판을 넣을 장면을 고르고, "소스" 목록 아래 + → 브라우저.
  2. 이름을 직업룰렛 현황판 으로 적고 확인.
  3. 속성 창 설정:
    • 로컬 파일 체크 → "찾아보기"로 roulette-board.html 선택
    • 너비 460, 높이 700 (리롤을 켰다면 높이 760)
    • 사용자 지정 CSS: 기본값 그대로
    • 표시되지 않을 때 소스 종료 · 장면 활성화 시 새로 고침: 둘 다 체크 해제
  4. 확인을 누르면 미리보기에 현황판이 나타나요. 배경은 투명이라 게임 화면 위에 판만 보여요. 처음엔 "아직 투표가 없어요"가 정상이에요.

위치·크기: 미리보기에서 현황판을 클릭해 끌면 위치가 바뀌어요. 크기는 모서리를 끄는 것보다 편집창의 크기 배율이 글씨가 선명해요. 배율을 키웠는데 아래가 잘리면 소스 속성의 너비·높이도 같은 비율로 늘리세요. 자리를 잡았으면 소스 목록의 자물쇠로 잠가 두세요.

3. 후원이 들어왔을 때 입력하기

  1. OBS 소스 목록에서 현황판 우클릭 → 상호작용. 방송 내내 켜둬도 돼요.
  2. 상호작용 창의 빈 곳을 클릭한 뒤 E 를 누르면 편집창이 열려요. (판 오른쪽 위에 마우스를 올리면 보이는 ⚙️ 버튼도 같아요.)
  3. 직업군별 직업 버튼을 눌러 고르고, +1표 / +5표 / +10표를 눌러요. 그 직업의 1표 금액만큼 자동으로 들어가요.
    • 메소 후원은 아래 노란 줄의 +표 버튼
    • 그 외 금액은 숫자를 적고 금액 추가 (메소는 억 단위 숫자 → 억 추가)
  4. 다 넣었으면 E 로 닫아요.
주의: 편집창도 현황판의 일부라서, 열려 있는 동안 시청자 화면에도 보여요. 입력이 끝나면 바로 닫으세요.
  • OBS 상호작용 창에서는 한글이 입력되지 않아요. 그래서 직업은 버튼으로 고르고 숫자만 키보드로 써요.
  • 1표 금액으로 나누어떨어지지 않는 금액은 총 후원에는 더해지고, 표는 내림으로 계산돼요.

4. 수정·취소·리롤

  • 방금 잘못 넣었을 때: ↩ 마지막 입력 취소 (여러 번 누르면 하나씩 되돌아감)
  • 특정 직업 표만 고칠 때: 편집창 직업 목록의 +1 / −1, 아예 빼려면 삭제
  • 리롤 후원: "리롤 사용 처리"에서 해당 회차 버튼 → "사용됨". 판의 칸에 ✓와 남은 횟수가 줄어요. 다시 누르면 취소
  • 처음부터 다시: 투표 전체 초기화를 두 번 연속. 되돌릴 수 없으니 테스트 후에만 쓰세요
  • 화면: 편집창 아래에서 한 페이지 개수, 넘김 간격, 크기 배율을 바로 바꿀 수 있어요

5. 설정 바꾸기 (제목·규칙·투표 불가 직업·테마)

  1. 설정 페이지를 다시 열어요. 같은 브라우저라면 지난 설정이 그대로 있고, 다른 PC라면 📂 저장한 파일 불러오기로 쓰던 roulette-board.html을 고르면 설정이 돌아와요.
  2. 고친 뒤 내 현황판 파일 저장 → 받은 파일로 기존 파일을 같은 폴더·같은 이름으로 덮어쓰기.
  3. OBS 소스 속성에서 현재 페이지 새로 고침. 쌓인 표는 그대로 남아요.
1표 금액을 바꾸면 쌓인 금액 기준으로 표 수가 다시 계산돼요. 표가 있는 직업을 투표 불가로 바꾸면 순위표에서 빠져요(다시 풀면 돌아옴).

문제 해결

증상해결
현황판이 안 보인다 / 하얀 화면소스 속성에서 "로컬 파일" 체크와 파일 경로를 확인하세요. 파일을 옮겼다면 다시 골라야 해요.
배경이 검거나 하얗다"사용자 지정 CSS"를 기본값으로 되돌리세요 (칸을 비우면 OBS가 다시 채워요).
판 아래쪽이 잘린다소스 속성의 높이를 늘리거나, 편집창에서 한 페이지 개수를 줄이세요.
E를 눌러도 편집창이 안 열린다상호작용 창의 빈 곳을 먼저 클릭하세요. 입력 칸에 커서가 있으면 E가 글자로 들어가요.
글씨체가 평범하게 바뀌었다인터넷 연결을 확인하고 "현재 페이지 새로 고침"을 누르세요. 글꼴을 인터넷에서 불러와요.
입력한 표가 사라졌다소스 속성의 "현재 페이지의 캐시 새로 고침"은 저장된 표를 지울 수 있어요. 누르지 마세요. 표는 그 PC의 OBS 안에만 저장돼요.
설정 페이지 미리보기가 안 나온다설정 페이지는 인터넷 주소(https://)로 열어야 해요. 받은 html을 더블클릭해서 여는 건 현황판 파일이에요.

후원 기록을 안전하게 남기려면, 방송을 마칠 때마다 현황판 화면을 한 장 캡처해 두세요.

방송 당일 체크리스트

시작 전

  • 현황판이 방송 장면에 보이고 채팅창·미니맵과 겹치지 않는다
  • 테스트로 넣은 표가 있었다면 "투표 전체 초기화"
  • 디데이·리롤 상태 확인
  • 편집창이 닫혀 있다

방송 중

  • 후원이 오면 직업 고르고 +표 → 편집창 닫기
  • 투표 불가 직업 후원은 방송에서 처리 방법 안내
  • 리롤 후원이 오면 해당 회차 "사용됨"

종료 후

  • 현황판 화면 캡처
