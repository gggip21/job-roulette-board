사용법

자세한 화면 설명은 사용 가이드(PDF)에 있어요.

파일 저장

위에서 설정하고 내 현황판 파일 저장. 파일은 지우지 않을 폴더(예: 문서\방송)에 두세요.

OBS에 추가

소스 + → 브라우저 → 로컬 파일 체크 후 파일 선택. 너비 460, 높이 700 (리롤 켜면 760).

후원 입력

소스 우클릭 → 상호작용 → E 키로 편집창. 직업 버튼 누르고 +1표. 입력 끝나면 E로 닫기.

자주 묻는 질문

후원이 자동으로 들어오나요?

아니요. 치지직·SOOP·유튜브 후원은 자동 연동되지 않아서, 후원이 오면 OBS 상호작용 창에서 직접 입력해요. 직업 버튼과 +1표 버튼이라 한 건에 몇 초면 돼요.

OBS 편집창에서 한글이 안 써져요.

OBS 상호작용 창은 한글 입력을 지원하지 않아요. 그래서 제목 같은 글자 설정은 이 페이지에서 하고, OBS에서는 버튼과 숫자만 써요.

설정을 바꾸면 쌓인 표가 사라지나요?

새로 저장한 파일로 같은 이름 그대로 덮어쓰면 표는 남아요. 1표 금액을 바꾸면 쌓인 금액 기준으로 표 수가 다시 계산돼요. OBS 소스 속성의 "캐시 새로 고침"은 표를 지울 수 있으니 누르지 마세요.

편집창이 방송에 보이나요?

네, 편집창도 현황판의 일부라 열려 있는 동안 시청자 화면에도 보여요. 입력이 끝나면 E 키로 바로 닫아 주세요.

새 직업이 나오면요?

이 페이지가 업데이트되면 다시 설정·저장해서 덮어쓰면 돼요. "저장한 파일 불러오기"로 예전 설정을 그대로 가져올 수 있어요.

🍁 이 현황판을 만든 사람이 넥슨 직업 추천 AWARDS에 영상으로 참가하고 있어요. 영상이 도움이 됐다면 투표로 응원해 주세요. 현황판은 투표와 상관없이 누구나 무료로 쓸 수 있어요.
