2.0 업데이트스킨 12종

생각보다 훨씬 많은 분들이 써 주셔서 정말 감사해요. 방송마다 다른 판을 쓸 수 있도록 스킨을 처음부터 새로 만들었어요. 크리스마스·겨울 눈·레트로 픽셀부터 종이·유리까지, 글꼴과 막대 모양, 후원 효과까지 스킨마다 달라요. 이미 쓰고 있던 판은 업데이트하면 크리스마스 이벤트 장식이 씌워져요.

스킨 구경하기
업데이트 내역

이미 쓰고 있다면: 아래 파일 설정 불러오기로 지금 쓰는 파일을 고르고 내 현황판 파일 저장으로 같은 파일에 덮어쓴 뒤, 현황판 편집창(E)에서 판 새로 고침을 누르세요. 표는 그대로 남아요. v1.6부터는 현황판에 뜨는 업데이트 창의 지금 업데이트 버튼 하나로 바뀌어요.

이미 쓰고 계신가요?

v1.6 이상 다음 방송 때 판 위에 뜨는 업데이트 창에서 지금 업데이트를 누르면 끝이에요. 표와 설정은 그대로예요.

v1.5 이하 아래 파일 설정 불러오기로 지금 쓰는 파일을 고르고 → 내 현황판 파일 저장으로 같은 파일에 덮어쓰기 → 현황판 편집창(E)에서 판 새로 고침. 한 번만 하면 다음부터는 버튼 하나로 업데이트돼요.

내 버전은 현황판 편집창(E) 화면 탭 맨 아래에서 볼 수 있어요. 버전이 안 보이면 v1.5 이하예요.

왼쪽에서 고치면 오른쪽 미리보기에 바로 반영돼요. 다 고쳤으면 내 현황판 파일 저장을 누르세요. 설정은 이 브라우저에 자동 저장돼요.

처음 설정을 잘못해도 괜찮아요. 다시 설정해서 받은 html 파일을 기존 파일에 덮어씌우면 득표수는 그대로 유지돼요.단, 표 금액을 바꾸면 쌓인 금액 기준으로 표 수가 다시 계산돼요.

다운 후 변경 가능태그가 붙은 칸은 받은 뒤에도 OBS 소스 우클릭 → 상호작용 창에서 E를 눌러 편집창에서프릭샷 소스 더블클릭 → 속성 창 상호작용에서 E를 눌러 편집창에서 바로 바꿀 수 있어요.태그가 없는 칸은 여기서 다시 설정해 받은 파일을 같은 파일에 덮어쓰면 바뀌어요. 표는 그대로예요.

투명진하게

표를 받은 직업이 한 페이지보다 많으면 자동으로 다음 페이지로 넘어가요. 크기는 OBS에서 조절해요.
이 칸의 설정은 다시 받지 않아도 현황판 편집창(E)에서 바로 바꿀 수 있어요.

후원 규칙

금액이 같은 직업끼리 한 그룹으로 묶어요. 다른 그룹에 있는 직업을 누르면 이 그룹으로 옮겨져요.

고른 직업은 현황판에 금액 배지가 붙고, +1표 버튼도 이 금액으로 들어가요.

억

투표 불가 · 선호 직업

누를 때마다없음→ 투표 불가→ 선호→ 없음

선호 직업은 판에 하트로 표시만 돼요. 표 금액·표 수에는 영향이 없어요.

리롤

위를 끄면 리롤은 처음엔 판에 안 보여요. 투표를 다 받은 뒤 편집창(E) 맨 위 집계 완료 · 추첨 시작을 누르면 판에 리롤 칸이 나오고 모든 회차가 미사용으로 시작해요. 리롤 후원이 오면 판의 리롤 칸을 눌러 사용 처리해요. 이 설정은 받은 뒤 편집창(E) "화면"에서도 바꿀 수 있어요.

디데이

저장할 때 알아 둘 것

저장되는 파일 이름은 roulette-board.html이에요. 설정을 바꿀 때는 저장 창에서 OBS에 넣어 둔 그 파일을 골라 덮어쓰세요. 그다음 OBS 상호작용 창에서 E → 판 새로 고침을 누르면 방송 중에도 바로 바뀌고, 쌓인 표도 그대로예요. 소스를 다시 넣을 필요는 없어요.

다운로드 폴더에 roulette-board (1).html처럼 새 파일이 생겼다면 OBS는프릭샷은 아직 예전 파일을 보고 있어요. 그 파일 이름을 원래대로 바꿔 기존 파일에 덮어쓰세요.

OBS 소스 크기 지금 설정에 맞춘 크기예요. 설정을 바꾸면 OBS 소스 속성의 높이도 이 숫자로 맞춰 주세요.

방송 프로그램

파일 저장

위에서 설정하고 내 현황판 파일 저장. 파일은 지우지 않을 폴더(예: 문서\방송)에 두세요.

OBS에 추가

소스 + → 브라우저 → 로컬 파일 체크 후 파일 선택.장면 소스 리스트 + → 브라우저 추가 → 속성 창에서 로컬 파일 체크 후 파일 선택. 크기는 .

후원 입력

소스 우클릭 → 상호작용소스 더블클릭 → 속성 창 맨 위 상호작용 → E 키로 편집창. 직업 버튼 누르고 +1표. 입력 끝나면 E로 닫기.

핀볼 추첨

종료 후 편집창에서 집계 완료를 누르면 자동으로 복사돼요. 핀볼 추첨 사이트에 붙여넣으면 직업과 표 수가 그대로 들어가요.

자주 묻는 질문

후원이 자동으로 집계되나요?

아직은 아니에요. 후원이 오면 OBS 상호작용 창에서 직접 입력해요. 직업 버튼과 +1표 버튼이라 한 건에 몇 초면 돼요. 많이 써 주시면 자동 집계도 개발해 볼 생각이에요.

새로 받았는데 방송 화면이 안 바뀌어요

① 받은 파일이 roulette-board (1).html처럼 다른 이름으로 저장되지 않았는지 보세요. OBS에 넣은 파일과 같은 위치·같은 이름으로 덮어써야 해요. ② 덮어쓴 뒤 OBS 상호작용 창에서 E → 판 새로 고침을 누르세요. 방송 중에도 되고 표는 그대로예요. 그래도 안 바뀌면 OBS를프릭샷을 껐다 켜세요(표는 남아요). 소스를 지우고 다시 넣을 필요는 없어요.

설정을 바꾸면 쌓인 표가 사라지나요?

새로 저장한 파일로 같은 이름 그대로 덮어쓰면 표는 남아요. 표 금액을 바꾸면 쌓인 금액 기준으로 표 수가 다시 계산돼요. 브라우저 소스 속성의 "캐시 새로 고침"은 표를 지울 수 있으니 누르지 마세요.

편집창이 방송에 보이나요?

네, 편집창도 현황판의 일부라 열려 있는 동안 시청자 화면에도 보여요. 입력이 끝나면 E 키로 바로 닫아 주세요.

새 직업이 나오면요?

이 페이지가 업데이트되면 다시 설정·저장해서 덮어쓰면 돼요. "파일 설정 불러오기"로 예전 설정을 그대로 가져올 수 있어요.
